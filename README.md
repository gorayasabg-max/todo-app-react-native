# React Native Todo App + Node/Express/MongoDB Backend

This project is prepared for a React Native CLI Android assignment.

## Included
- React Native mobile app
- NativeWind/Tailwind-style classes
- Add, complete/uncomplete, delete and refresh todos
- Node.js + Express backend
- MongoDB/Mongoose database
- Offline fallback using AsyncStorage

## Important
The ZIP contains the complete JavaScript/backend source. Because the Android native folder is generated by the React Native CLI for the exact local Android SDK/Gradle environment, run `setup.bat` once on Windows before opening the Android folder in Android Studio. This avoids shipping a native folder that may mismatch your installed SDK.

## 1. Backend
Open Command Prompt in `backend`:

    npm install

Copy `.env.example` to `.env` and put your MongoDB Atlas URI in `MONGO_URI`.

Then:

    npm run dev

You should see `MongoDB Connected` and `API running on http://localhost:5000`.

## 2. Mobile setup
Open `mobile` in Command Prompt and run the root `setup.bat` first. It creates the Android native project and installs JS packages.

After setup:

    cd mobile
    npm start

In another terminal:

    cd mobile
    adb reverse tcp:8081 tcp:8081
    adb reverse tcp:5000 tcp:5000
    npm run android

The first reverse command connects Metro; the second connects the phone's app to the backend over USB.

## 3. Physical Android phone
1. On the phone enable Developer Options by tapping Build Number 7 times.
2. Enable USB Debugging.
3. Connect phone with a data USB cable.
4. Accept the `Allow USB debugging` prompt.
5. Run `adb devices`.
6. It should show your phone as `device`.
7. Run the two `adb reverse` commands above and `npm run android`.

React Native's official Android-device documentation recommends USB debugging, `adb devices`, and `adb reverse` for a USB-connected device.

## 4. Android Studio
After `setup.bat` finishes, open:

    mobile/android

in Android Studio. Let Gradle sync. Select the connected phone from the device selector and press Run.

If Android Studio shows a Gradle/JDK/SDK mismatch, do not randomly change versions. Send the exact error screenshot and it can be fixed against the installed environment.

## 5. Wi-Fi alternative
USB is easier for the first run. After the app is installed, Wi-Fi debugging can be configured, but the laptop and phone must be on the same network and the API URL must use the laptop's LAN IP instead of `127.0.0.1`.
